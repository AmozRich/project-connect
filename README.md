# Project Connect

A role-based student project management system designed to streamline project submission and approval in colleges.

## Roles
- Student
- Faculty Guide
- Head of Department (HOD)

## Features
- Students can submit project proposals
- Faculty guides can approve or reject proposals
- HOD provides final approval
- Role-based dashboards
- Secure JWT authentication

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB Atlas

## Use Case
Designed to simplify and digitize the student project approval workflow in academic institutions.
